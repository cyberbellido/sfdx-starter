# Org configuration

Update this file after authenticating your first org.

| Field | Value |
|-------|-------|
| Default alias | _(set after `sf org login web`)_ |
| Login URL | https://login.salesforce.com |
| Environment | _(scratch / sandbox / production)_ |

## Login

```bash
sf org login web --alias my-org --set-default
sf org list
```
